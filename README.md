# Thesis Indexer

This project helps you create an index of figures and tables in your LaTeX thesis. It scans your .tex file and compiles a list with page references for easy navigation. 

## How to Use
1. Place your LaTeX file in the same directory as this indexer.
2. Open `index.html` in your browser.
3. Upload your .tex file using the provided input.
4. Click on 'Generate Index' to see the list of figures and tables.

Designed for those who appreciate the structure and clarity in academic writing, especially in the realms of philosophy and art history.
